# 执行会话 05：长期记忆

主参考：[Mem0](https://github.com/mem0ai/mem0)。

## 会话使命

在知识库之外增加有边界的用户、会话和组织记忆，解决偏好与交互历史问题。

## 必做任务

1. 阅读 Mem0 的 add/search/update/delete/history、graph memory、作用域和评测设计。
2. 明确短期状态、情节记忆、语义记忆、用户偏好和企业知识的边界。
3. 设计写入判定、归并、冲突、衰减、TTL、删除、导出和用户可见控制。
4. 记忆检索接入 Context Service，并受 tenant/user/purpose 权限约束。
5. 评测有记忆与无记忆时的任务成功率、错误个性化、隐私泄漏和成本。

## 验收门槛

- 记忆有明确 owner、scope、来源、置信度、时间和生命周期；
- 用户能查看、纠正和删除自己的记忆；
- 不把所有聊天内容自动永久写入；
- 隔离、注入和过期测试通过。

结束时交接记忆策略和删除验证。
