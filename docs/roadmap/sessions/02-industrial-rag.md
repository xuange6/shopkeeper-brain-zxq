# 执行会话 02：工业 RAG

主参考：[RAGFlow](https://github.com/infiniflow/ragflow)。

## 会话使命

将现有固定 fan-out 查询图改造成可配置、可诊断、可评测的检索系统。

## 必做任务

1. 追踪 RAGFlow 从 dataset/chunk 到 retrieval/rerank/citation 的真实调用链和配置边界。
2. 以阶段 1 IR 为输入，明确 sparse、dense、metadata、graph、HyDE、Web 的适用条件和失败降级。
3. 把 query rewrite、召回、融合、重排、截断、引用和拒答拆成可观测步骤；保留每步候选及分数。
4. 用阶段 0 数据集比较策略，而不是只调单一相似度阈值。
5. 建立索引版本、参数版本、重建和回滚契约。

## 验收门槛

- 检索策略可由配置/查询计划选择，不再对所有问题无条件并发全部通道；
- 结果包含来源、结构位置、各阶段分数和最终入选原因；
- 空证据、低置信度和依赖故障都有确定行为；
- 质量、延迟和成本相对阶段 0 有可复查对比。

结束时交接胜出策略、退化样例和配置默认值，不扩张到知识生命周期。
