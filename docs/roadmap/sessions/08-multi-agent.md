# 执行会话 08：多智能体协作

主参考：[DeerFlow](https://github.com/bytedance/deer-flow)。

## 启动条件

只有阶段 6 的单 Agent 基线已稳定，并且真实任务显示职责分解能改善质量、并行度或上下文隔离时才启动。

## 会话使命

以明确协议组织少量专业 Agent，量化协作收益，控制通信、冲突和成本。

## 必做任务

1. 阅读 DeerFlow supervisor/planner、researcher、tool、memory/context 和 workflow 的边界。
2. 从一个单 Agent 明确失败的任务切入，定义角色能力、输入输出契约和共享/私有状态。
3. 实现委派、预算、截止时间、取消、结果合并、冲突解决和失败降级。
4. 防止循环委派、上下文爆炸、权限扩散和重复工具调用。
5. 与阶段 6 单 Agent 做盲测，比较成功率、延迟、token、调用量和可解释性。

## 验收门槛

- 多 Agent 在预先定义的目标上有显著、可重复收益；
- 不达收益门槛时保留单 Agent，并记录否决结论；
- 任一子 Agent 失败可定位、取消或降级；
- 角色权限遵循最小授权。

结束时交接是否采用的证据，而不是默认上线多 Agent。
