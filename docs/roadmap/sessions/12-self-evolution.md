# 执行会话 12：受控自进化

主参考：[OpenEvolve](https://github.com/codelion/openevolve)。

## 启动条件

必须已有可靠自动评测、隔离执行、版本管理和回滚；否则本阶段只做调研，不允许自动应用变更。

## 会话使命

建立“生成候选—隔离评测—选择—人工审查—灰度”的受控优化闭环。

## 必做任务

1. 阅读 OpenEvolve population/database、prompt、evaluator、selection 和 iteration loop。
2. 选择低风险、可自动评分的对象，如检索参数、Prompt 或纯函数策略。
3. 固定训练/验证/保留集，防止对公开评测过拟合；记录谱系和实验配置。
4. 所有候选在沙箱运行，设置资源预算、失败隔离和停止条件。
5. 只有超过预设收益且无安全退化的候选才能人工审查和灰度。

## 验收门槛

- 每个候选可复现、可比较、可回滚；
- 保留集验证收益，安全/成本指标没有越界；
- 自动系统没有生产写权限；
- 无收益时能停止并保留否决证据。

结束时交接实验谱系与风险边界。
